Creates a time partitioned table for BigQuery backend projects. The created table must only contain Primary Key column (not nullable), and the colmnn that will be used for time partitioning (DATE or TIMESTAMP). After creation, new columns can be added and values inserted. 

Need to optimize BigQuery performance and costs? This template creates time-partitioned tables that automatically organize your data by time intervals, reducing query costs and improving performance. Perfect for organizations dealing with time-series data or requiring efficient historical data analysis.

Get started in minutes: Simply specify your table name, primary key column, and time partition settings. The template will create an empty table with time partitioning enabled - ready for you to load data and add additional columns through BigQuery SQL transformations.

Need to track when and which tables are being deleted in your Keboola project? This template helps you monitor and audit table deletions by automatically collecting deletion events. Perfect for data governance, auditing, and maintaining visibility into your storage operations.

Get started in minutes: Simply provide your project ID and the template will start tracking all table deletion events, giving you a clear view of what tables were deleted, when, and by which tokens. The data is loaded incrementally, so you'll always have up-to-date information without duplicates.

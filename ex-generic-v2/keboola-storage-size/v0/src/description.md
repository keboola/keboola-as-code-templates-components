Need to monitor your Keboola project's storage usage and track table growth over time? This template automatically collects comprehensive statistics about all tables in your project, helping you optimize storage costs and understand data growth patterns.

Get started in minutes: Simply provide your storage token and hostname, and the template will begin tracking table sizes, row counts, and modification dates. You'll see a complete overview of your storage usage in the first run, with incremental updates keeping the information current.

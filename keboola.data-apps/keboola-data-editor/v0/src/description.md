Need to edit data directly in Keboola without complex exports and imports? This template provides a spreadsheet-like interface for business users to safely modify data stored in Keboola Storage. Perfect for teams that need to make regular data updates without technical intervention.

Get started in minutes: Simply configure a storage token with access to your target tables, deploy the app, and start editing your data through an intuitive interface. Changes are immediately reflected in your Keboola Storage tables, with built-in validation to prevent errors.

A comprehensive demonstration of Streamlit capabilities within Keboola Data Apps. This template showcases common Streamlit widgets and features through an interactive web application.

## Configuration
- No additional configuration required
- Authentication disabled by default for easy testing
- Runs as a standalone Data App

### Required Parameters
No parameters required - the template works out of the box.

## Output Data
This is a demonstration app that doesn't produce output tables. It showcases:
- Interactive widgets
- Data caching
- File upload handling
- Column layouts
- User input processing

## Features
- Text input and display
- Slider controls
- Dropdown selection
- File upload capability
- Cached data loading simulation
- Side-by-side column layout
- Interactive buttons
- Conditional content display
